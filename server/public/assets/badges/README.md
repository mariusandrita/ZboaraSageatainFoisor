Drop custom badge artwork in this folder and the apps will pick it up automatically.

Naming:
- Use the badge kind as the filename, for example `breakfast.png`, `180.webp`, `bullFinish.svg`.
- Supported extensions are `.png`, `.webp`, `.jpg`, `.jpeg`, and `.svg`.

Known badge kinds:
- `180`
- `bailOut`
- `beatGeneral`
- `bigDouble`
- `bigTriple`
- `blackHat`
- `breakfast`
- `bucket`
- `bullFinish`
- `bust`
- `centrul`
- `hamster`
- `highFinish`
- `lowTriple`
- `lunetist`
- `madhouseEscape`
- `matematician`
- `overAvg`
- `shanghai`
- `threeMisses`
- `ton100`
- `ton140`
- `zugrav`

Tips:
- Square images around `512x512` work best.
- Transparent backgrounds are supported.
- If a file is missing, the UI falls back to an auto-generated badge image, so you can replace them gradually.
